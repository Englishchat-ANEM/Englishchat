🚀 PROCHAINES ÉTAPES:

ÉTAPE 1 - Push vers GitHub (5 min)
──────────────────────────────
  1. Va https://github.com/Englishchat-ANEM/englishchat
  2. Clone le repo vide
  3. Ajoute tout ce code
  4. Push vers main

  $ git clone https://github.com/Englishchat-ANEM/englishchat.git
  $ cd englishchat
  $ cp -r [ce_code_ici]/* .
  $ git add .
  $ git commit -m "Initial commit: EnglishChat full stack"
  $ git push origin main

ÉTAPE 2 - Déployer sur Vercel (5 min)
─────────────────────────────────
  1. Va https://vercel.com/new
  2. Sélectionne ton repo GitHub
  3. Root directory: ./frontend
  4. Click "Deploy"
  5. ✅ Frontend live!

ÉTAPE 3 - Déployer sur Railway (10 min)
──────────────────────────────────
  1. Va https://railway.app/new
  2. "Deploy from GitHub"
  3. Root directory: ./backend
  4. Click "Deploy"
  5. Ajoute PostgreSQL service
  6. Initialise DB (exécute schema.sql)
  7. ✅ Backend live!

ÉTAPE 4 - Configure Variables (5 min)
─────────────────────────────────
  Vercel:
    VITE_API_URL = https://api.englishchat.app/api
    VITE_SOCKET_URL = https://api.englishchat.app

  Railway:
    NODE_ENV = production
    PORT = 3000
    JWT_SECRET = [cle_longue_complexe]
    FRONTEND_URL = https://englishchat.app

ÉTAPE 5 - Domain (Optionnel, 10 min)
──────────────────────────────────
  1. Achète englishchat.app (~$10)
  2. Configure Vercel domain
  3. Configure Railway domain (api.englishchat.app)
  4. ✅ App live sur domain custom!
